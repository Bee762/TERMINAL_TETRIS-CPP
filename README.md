#TERMINAL TETRIS (C++)

A terminal based tetris game written on c++ using console rendering.
This project was built to practice c++ fundamentals , game loops ,input handling, and basic game logic

## Features of the project : 
~ random shape generation
~ rendering the shape in main board
~ movement of the shape
~ user input handling 
~ rotation with keypress
~ gravity
~ collision checks
~ hard drop
~ locking piece in main board
~ line clearing
~ pause and resume
~ score tracking and saving in device
~ terminal-based rendering
~ storing a falling piece and use that piece later
~ colours using ansi escape codes
and many more :)

## Controls :
controls are detailed in the game rulebook,read it before playing

## Technologies used :
~ c++
~ standard library
~ windows console APis (for input)
